## Getting Started

Clone from Github 
```
git clone https://github.com/themewagon/Oberlo.git
```

## Formulário de contato

O formulário valida nome, telefone, e-mail e mensagem. Ao enviar, abre o aplicativo de e-mail padrão com os dados preenchidos para `contato@sonhovivo.com.br`; revise a mensagem e clique em Enviar no aplicativo. Não é necessário configurar servidor ou credenciais de e-mail.

Para executar o site localmente, instale o Node.js e rode `npm start`. Ele ficará disponível em `http://localhost:3000`. Execute `npm test` para verificar a página e os arquivos públicos.
